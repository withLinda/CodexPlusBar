# CodexPlusBar 1.7.9 (build 32)

The profile manager and menu bar now share the same filter and navigation logic. Filter counts are calculated in one pass. Arrow keys follow the visible search and sort order, even when some profiles are hidden. The menu bar skips redraws when its title and icon have not changed.

A pin controls which account's usage you see. A different account with 20% or less remaining in its five-hour window can still trigger the warning icon. iCloud catalog merges keep cloud order and append local-only profiles in their saved order without repeatedly searching the whole list.

## Install or update

1. Download **[CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.9/CodexPlusBar.dmg)** for macOS 14 or later (Apple silicon and Intel).
2. Quit any running copy. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** if updating.
3. Eject the DMG and open CodexPlusBar from Applications. Look for it in the menu bar. Existing profiles and sign-ins stay in place; iCloud Sync remains opt-in.

## Optional: Account Priority for OpenChamber

This release includes a fresh build of **Account Priority 0.3.0**. If you already have 0.3.0, no extension update is required for the Mac app changes.

For a new installation or an older extension, download **[expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.9/expiry-selector.zip)** and extract it. If Auto is running, pause it first. In **OpenChamber → Settings → Extensions**, select the extracted `expiry-selector` folder, approve the requested capabilities, and reload. Check the accounts before enabling Auto.

**[SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.9/SHA256SUMS)** covers both downloads. To check them on a Mac, put all three files in the same folder and run `shasum -a 256 -c SHA256SUMS` there. Both filenames should report `OK`.
