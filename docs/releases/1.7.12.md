# CodexPlusBar 1.7.12 (build 35)

**Queue is the new Mac app icon.** In Finder, look for one orange disc on pine green, with two smaller discs behind it. The menu bar still shows live account status.

## Install or update

1. [Download CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.12/CodexPlusBar.dmg) for Apple silicon or Intel (macOS 14 or later).
2. Quit CodexPlusBar if it is running. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** if asked.
3. Eject the DMG and open CodexPlusBar from Applications. Your saved profiles and sign-ins stay in place. iCloud Sync stays opt-in.

## Optional OpenChamber extension

This release includes a fresh [Account Priority 0.3.0 ZIP](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.12/expiry-selector.zip). If 0.3.0 is already installed, keep it. For a new installation, extract the ZIP, select the **expiry-selector** folder in **OpenChamber → Settings → Extensions**, then reload the extension.

To check the downloads, put the DMG, the ZIP and [SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.12/SHA256SUMS) in the same folder. Run `shasum -a 256 -c SHA256SUMS` there; both files should report `OK`.
