# CodexPlusBar 1.7.8

## Account Priority 0.3.0: keep Auto working across compatible updates

- Restore Auto on **OpenChamber 2.7.2 / OpenCode 2.3.0**.
- Remove the exact OpenCode version allowlist that caused the same block after each update. Compatible future releases no longer need a version-list change.
- Check the required native account APIs, all five registered request/retry hooks and the lifecycle event subscription before enabling automatic selection.
- Explain actual missing APIs, failed/incomplete hooks and disconnected lifecycle events. Partial setup keeps status controls available and cleans up registered hooks.
- Preserve full-weekly-quota priority, earliest-expiry fallback, native OAuth refresh, identity/freshness checks, cooldowns, maintenance and activation confirmation.

Capability checks do not guarantee unreleased API behavior. A genuine breaking API or hook change can still require an extension update.

## Install or update the Mac app

1. Download **[CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.8/CodexPlusBar.dmg)** for macOS 14+, Apple silicon or Intel.
2. Quit CodexPlusBar. If its menu is missing, open the app from Applications and press **⌘Q** in its window.
3. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** when updating.
4. Eject the DMG, reopen the app, refresh your accounts and keep it running.

The Mac app is **1.7.8, build 31**. Existing profiles/sign-ins stay in place; iCloud Sync remains opt-in on each Mac.

## Install or update the OpenChamber extension separately

**Download both files if you use automatic switching.** The DMG does not update an extension already installed in OpenChamber.

1. If Account Priority is installed, choose **Pause Auto** and wait for acknowledgement.
2. Download **[expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.8/expiry-selector.zip)** and extract it in Finder.
3. In **OpenChamber → Settings → Extensions**, install or replace the extension by selecting the extracted **expiry-selector** folder, not the ZIP. Approve its plugin and local-service capabilities and reload the updated extension.
4. Confirm extension version **0.3.0**, recheck the accounts, disable competing native limit-switch/fallback settings, and explicitly enable or resume Auto.

Repeat on each Mac with the extension. An older version's compatibility error requires replacing the extension; Recheck alone cannot update its code. See the [extension guide](https://github.com/withLinda/CodexPlusBar/blob/v1.7.8/Extensions/expiry-selector/README.md).
