# CodexPlusBar 1.7.0 — Opt-in iCloud account sync

Universal macOS 14+ installer for Apple silicon and Intel. Version **1.7.0**, build **23**.

## Download and install

1. Download [CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.0/CodexPlusBar.dmg).
2. Quit CodexPlusBar if it is running. Open the DMG and drag **CodexPlusBar.app** onto **Applications**; choose **Replace** when updating.
3. Eject the DMG and open CodexPlusBar from Applications. The app lives in the menu bar. Existing profiles and saved sign-ins stay in place.

The app and DMG are Developer ID-signed, notarized by Apple, and stapled. Download `SHA256SUMS` beside the DMG, then run `shasum -a 256 -c SHA256SUMS` from their download folder to verify the file.

## What's new

- Opt-in **Settings → iCloud Sync → Sync accounts with iCloud** merges profile details, passwords, and 2FA secrets between Macs using the same iCloud account.
- **Include saved login sessions** starts on when sync is enabled. Browser, Codex desktop, and OpenChamber snapshots appear in **Saved sessions from iCloud** for explicit import.
- Incoming sessions prefer a working local login. Native imports save without selecting the account; choose **Switch** to activate it. Expired or independently rotated logins can require **Repair both** or a fresh sign-in.
- Offline changes merge with field-level versioning and retained deletion markers. Restoring a backup pauses cloud publication until you explicitly re-enable sync.
- Payloads are AES-GCM encrypted in the private CloudKit database; app-owned keys travel through iCloud Passwords & Keychain. Each Mac's native selection and browser stores remain local.

## Enable on another Mac

Install 1.7.0 on both Macs, sign in to the same iCloud account, and enable **Passwords & Keychain** in System Settings. Enable iCloud Sync separately on each Mac. Use **Sync Now** to retry; **Waiting for iCloud Keychain** means the encryption key has not arrived. For a saved login, choose **Reload**, then **Import saved session** for the source Mac you want.

Sync stays off after installation or upgrade until you opt in. Turning sync or session sharing off stops new work and retains existing copies. Password-encrypted Backup & Transfer remains available.

## Verification boundary

The final implementation passed 54 targeted Swift tests in three suites, native preview checks, and five release-preflight tests. Signed Apple service probes verified account access, encrypted asset roundtrips, local synchronizable Keychain access, APNs registration, and subscription creation.

The fresh 1.7.0 archive passed strict compilation for both architectures. App and DMG notarization, staple validation, Gatekeeper, mounted-app Production signing preflight, and the final checksum passed. The five release-preflight tests passed again for this release.

**Live two-Mac acceptance, cross-device Keychain delivery, automatic push delivery, and provider-dependent import/Switch/Repair acceptance remain pending.** Synthetic replicas and single-Mac service probes do not establish those results. See the [validation record](https://github.com/withLinda/CodexPlusBar/blob/v1.7.0/docs/releases/2026-11-09-cloudkit-sync-validation.md) for the evidence and remaining checks.

Local passwords, 2FA secrets, and saved sign-in files are not encrypted by CodexPlusBar. Cloud payload encryption and password-encrypted backups do not change that local-storage behavior.
