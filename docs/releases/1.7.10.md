# CodexPlusBar 1.7.10 (build 33)

Fixes sustained CPU use when iCloud Sync has a large history of saved sessions. Ordinary restarts resume from the last usable CloudKit checkpoint. Previously processed sessions stay available for import without being replayed one by one, and a local usage refresh no longer starts a cloud sync just because its timestamp changed.

On the affected Mac, the previous version used about one CPU core for over 15 hours. With the fix, all 4,272 receipts were processed, the save queue emptied, and CPU averaged 2.1% in each of two consecutive 50-second windows. Active sync can still briefly use more CPU and memory.

## Install or update

1. Download **[CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.10/CodexPlusBar.dmg)** for macOS 14 or later (Apple silicon and Intel).
2. Quit CodexPlusBar. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** when updating.
3. Eject the DMG and open CodexPlusBar from Applications. Your profiles, sign-ins, and sync history stay in place. iCloud Sync remains opt-in.

## Optional OpenChamber extension

Download **[expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.10/expiry-selector.zip)** for a fresh build of Account Priority **0.3.0**. If you already use 0.3.0, this sync fix only requires the DMG. To install or replace the extension, pause Auto if enabled, extract the ZIP, select the `expiry-selector` folder in **OpenChamber → Settings → Extensions**, and reload.

**[SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.10/SHA256SUMS)** covers both downloads. Put all three files in one folder and run `shasum -a 256 -c SHA256SUMS` there.
