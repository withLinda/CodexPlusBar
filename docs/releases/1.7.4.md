# CodexPlusBar 1.7.4

## Fixed

- Fixed iCloud downloads failing in apps launched normally from Finder or Applications. CloudKit grants access to each downloaded file, but opening its protected parent folder can be denied. The reader now opens the granted file directly while retaining bounded reads, ownership checks, and kernel-enforced rejection of symlinks throughout its path.
- Fixed the app terminating during a sync recovery retry. Background retries and cancellation now leave CloudKit's delegate task context before calling the engine again, while retaining serialized processing, epoch checks, and operation draining.
- Includes the earlier overlapping-upload and sync-status corrections.

## Update

Quit CodexPlusBar, replace it in Applications using **CodexPlusBar.dmg**, and reopen it on both Macs. Enable iCloud Sync if needed, then choose **Sync Now**. Existing accounts and queued changes are retained; no reset is needed.

## OpenChamber extension

This release also includes **[expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.4/expiry-selector.zip)**, freshly built Account Priority **0.1.0**. Extract it and install the **expiry-selector** folder in **OpenChamber → Settings → Extensions**. It is optional and separate from iCloud Sync. **SHA256SUMS** covers both the DMG and extension ZIP. Future releases include a fresh build of the current extension under this stable asset name.

## Verification

Installed 1.7.3 crash reports were symbolicated to the recovery fetch, and system logs contained CloudKit's exact delegate-reentry assertion. A signed probe launched through macOS LaunchServices reproduced both the denied download and the crash. With these corrections, it read the existing 45-profile cloud catalog successfully and recovered from an injected callback failure without crashing.

A separate normally launched signed probe uploaded 122 synthetic encrypted records, downloaded all 122, and verified exact decrypted contents. Temporary cloud records were removed. Targeted automated checks cover file-access restrictions, path validation, storage recovery, token expiry, network retry, account invalidation, and the 45/33-account replica scenario. See the [validation record](2026-11-09-cloudkit-sync-validation.md).

The app and DMG are Developer ID-signed, notarized, and stapled. **SHA256SUMS** is included. Live acceptance on both physical Macs remains pending.
