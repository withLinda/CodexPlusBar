# CodexPlusBar 1.6.2 (build 22)

## Codex-only account management

CodexPlusBar now supports Codex / OpenAI accounts only. Claude usage tracking, browser sign-in handling, provider selection, and Claude styling have been removed. Codex quota refresh, subscription expiry, ChatGPT / Codex switching, OpenChamber switching and Account Priority continue to use their existing flows.

Existing Claude records remain stored as inactive data and are hidden from the profile list. Editing or removing a Codex profile preserves those records. Startup maintenance protects their browser folders. Older mixed-provider backups remain restorable, but inactive provider cookies are not activated.

## Install or update

1. Download [CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.6.2/CodexPlusBar.dmg).
2. Quit CodexPlusBar if it is running. Open the DMG and drag **CodexPlusBar.app** onto **Applications**; choose **Replace** when updating.
3. Eject the DMG and open CodexPlusBar from Applications. Find it in the menu bar, open **Manage profiles**, and add or refresh a Codex account. No provider selection is needed.

Requires macOS 14 or later. The universal app supports Apple silicon and Intel.

The optional [Account Priority extension](https://github.com/withLinda/CodexPlusBar/releases/download/v1.6.2/expiry-selector-0.1.0.zip) remains version **0.1.0**, byte-identical to the previous release. Existing extension installations do not need to reinstall it. [SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.6.2/SHA256SUMS) covers both downloads.

## API and saved-data compatibility

- `ProfileProvider` preserves raw string IDs during Codable roundtrips; only `.codex` is selectable. Missing provider fields still default to Codex, while unsupported IDs no longer become Codex silently.
- `PlusProfileController.storedProfiles` includes active and inactive records for persistence, backup counts, and startup folder protection. The live `profiles` list contains only Codex records loaded from disk. `setProvider(_:for:)` is removed.
- `BackupSessionBridge` collects and restores only Codex cookies. Backup validation still accepts structurally valid inactive-provider records, so older mixed catalogs remain usable without launching those sessions.
- `ChromeProfileStore.migrateAndPrune(profiles:)` protects all stored browser IDs from orphan cleanup while migrating and pruning only Codex profiles.
- Claude bootstrap, usage, request signing, URL definitions, organization runtime state, and saved-Chrome-cookie recovery APIs are removed. Codex authentication and quota endpoints, backup schema version 1, and selector schema/version remain unchanged.
