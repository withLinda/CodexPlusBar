# CodexPlusBar 1.7.11 (build 34)

Fixes **Check unavailable** when the local OpenChamber 2.8.0 app is already running. CodexPlusBar now verifies which server OpenChamber started instead of relying on the old launcher name. It also waits for the OpenAI integration if the first account check arrives during startup. If it still cannot check, the status explains the reason. An unchecked profile is not evidence of an expired sign-in.

## Install or update

1. Download [CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.11/CodexPlusBar.dmg) for macOS 14 or later (Apple silicon or Intel).
2. Quit CodexPlusBar. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** if asked. You can leave OpenChamber open.
3. Eject the DMG, open CodexPlusBar from Applications, and choose **Check sign-ins**. Your profiles and saved sign-ins stay in place. iCloud Sync stays opt-in on each Mac.

## OpenChamber extension

The release includes a fresh [expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.11/expiry-selector.zip) built from Account Priority **0.3.0**. If that version is already installed, only the DMG needs updating. For a new installation, extract the ZIP and select the **expiry-selector** folder in **OpenChamber → Settings → Extensions**. Pause Auto before replacing an existing extension, then reload it.

To verify the downloads, place [SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.11/SHA256SUMS), the DMG, and the ZIP in one folder. Run `shasum -a 256 -c SHA256SUMS`. Both files should report `OK`.
