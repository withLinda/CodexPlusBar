# CodexPlusBar 1.7.3

## Fixed

- Fixed iCloud uploads failing when automatic and manual sync overlap. An early completion could remove encrypted files while another upload still needed them. Files now remain available until their own result or the completion of all overlapping sends.
- Saved sessions that have arrived safely now count as synced while they wait for explicit import. Receiving a session does not sign in or switch a native app automatically.
- Includes the earlier iCloud checkbox and profile-refresh fixes.

## Update

Quit CodexPlusBar, replace it in Applications using **CodexPlusBar.dmg**, and reopen it on both Macs. Enable iCloud Sync if it is off, then choose **Sync Now**. Existing local accounts and queued changes are retained; no reset is needed.

## Verification

The original failure was reproduced against Apple's Production CloudKit service using a disposable zone and synthetic data: all 122 uploads failed with missing-file errors. With the correction, all 122 uploaded successfully and their downloaded, decrypted contents matched exactly. Temporary cloud records and subscriptions were removed.

Targeted tests cover overlapping completion, retained acknowledgements, incomplete sends, 45/33 overlapping account catalogs, 122 saved sessions, restart, and sync status before explicit import. See the [validation record](2026-11-09-cloudkit-sync-validation.md).

The app and DMG are Developer ID-signed, notarized, and stapled. The release includes **SHA256SUMS**. Live acceptance on both physical Macs remains pending.
