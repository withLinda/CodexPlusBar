# CodexPlusBar 1.7.2 — iCloud enablement fix

Universal macOS 14+ installer for Apple silicon and Intel. Version **1.7.2**, build **25**.

## What this fixes

In 1.7.1, checking **Sync accounts with iCloud** could immediately turn it off and show **“Waiting for iCloud sign-in”**, even with a working iCloud account.

A fresh CloudKit sync engine reports an initial sign-in to the account the app already verified. The app incorrectly treated that event as an account replacement and revoked sync consent. Version 1.7.2 recognizes that matching sign-in and keeps sync enabled. Real sign-outs, account switches, and sign-ins to a different account still stop sync and require consent again.

This release also includes the 1.7.1 profile-refresh/storage-path fix.

## Install and enable

1. Download [CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.2/CodexPlusBar.dmg).
2. Quit CodexPlusBar, open the DMG, drag **CodexPlusBar.app** onto **Applications**, and choose **Replace**.
3. Reopen the app and enable **Settings → iCloud Sync → Sync accounts with iCloud** again. The earlier failure turned this setting off, so updating alone does not re-enable it.
4. Install this version on the other Mac too, use the same Apple Account with iCloud Keychain enabled, and enable sync there. Choose **Sync Now** on each Mac.

Existing profiles and saved sign-ins are preserved. Saved login sessions still require explicit import on the receiving Mac; Codex/OpenChamber then use **Switch** to activate an imported login.

## Verification

- The regressions first reproduced transport shutdown, disabled Settings, and revoked consent before the fix.
- **82 targeted tests in three suites passed** after the fix: CloudKit transport, coordinator, and presentation. Coverage includes startup/repeated same-owner sign-in, Settings/restart persistence, sign-out and both account-switch directions, blocked late callbacks, and retained pending local work.
- A Developer ID-signed Production probe linked the actual app delegate object code. Live CloudKit emitted one matching sign-in, zero invalidations, four state updates, and one completed empty-scope fetch. Its temporary subscription was removed; account records and local profiles were not modified.
- Five release-preflight tests, the strict universal archive, app/DMG notarization, staple validation, Gatekeeper, mounted-app Production preflight, and final checksum passed.
- No full test suite was run. Real two-Mac convergence, cross-device Keychain/push delivery, and provider-dependent import/Switch/Repair acceptance remain pending in the [validation record](https://github.com/withLinda/CodexPlusBar/blob/v1.7.2/docs/releases/2026-11-09-cloudkit-sync-validation.md).

The app and DMG are Developer ID-signed, notarized, and stapled. Download `SHA256SUMS` beside the DMG and run `shasum -a 256 -c SHA256SUMS` from their download folder to verify the file.
