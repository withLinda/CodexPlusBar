# CodexPlusBar 1.7.7

## Account Priority 0.2.1: OpenChamber update compatibility

- Restore Auto selection on **OpenChamber 2.7.1 / OpenCode 2.2.7**. Earlier extension versions accept only OpenCode 2.2.6 and report “This OpenCode version has not passed compatibility checks” after the host update.
- Retain support for **OpenChamber 2.7.0 / OpenCode 2.2.6**. Unknown runtime versions remain blocked until tested.
- Share the exact verified-version list between the selection guards and displayed compatibility information.
- Preserve full-weekly-quota priority, earliest-expiry fallback, identity verification, freshness checks and cooldown handling.

## Install or update the Mac app

1. Download **[CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.7/CodexPlusBar.dmg)** for macOS 14 or later, Apple silicon or Intel.
2. Quit CodexPlusBar. If its menu is missing, open it from Applications and press **⌘Q** in its window.
3. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** when updating.
4. Eject the DMG and open CodexPlusBar from Applications. Refresh your accounts and keep the app running.

The app is version **1.7.7**, build **30**. Existing profiles and saved sign-ins stay in place, and iCloud Sync remains opt-in on each Mac.

## Install or update the extension separately

The compatibility fix requires this release's freshly built **[expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.7/expiry-selector.zip)**, containing Account Priority **0.2.1**. Updating only the DMG does not update an extension already installed in OpenChamber.

1. On an existing extension, choose **Pause Auto** and wait for acknowledgement.
2. Download and extract the ZIP. Install or replace its **expiry-selector** folder in **OpenChamber → Settings → Extensions**, approving the plugin and local-service capabilities.
3. Confirm version **0.2.1**, recheck the accounts, disable competing native limit-switch/fallback settings, and explicitly enable or resume Auto.

Repeat the extension update on each Mac where it is installed. No OpenChamber downgrade is needed for the two verified version pairs above. See the [extension guide](https://github.com/withLinda/CodexPlusBar/blob/v1.7.7/Extensions/expiry-selector/README.md) for recovery details.
