# CodexPlusBar 1.7.5

## Fixed

- Restored menu-bar startup when iCloud Sync is enabled. The menu now appears before cloud identity, download and upload work completes.
- Restored the fresh account-data feed used by OpenChamber Account Priority. Local refresh and selector publication start as soon as the local catalog is safe to use.
- Preserved pending catalog/restore recovery protection for both background work and manual actions. First-use cloud merging protects fetched remote fields before awaiting native-operation cleanup.
- Prevented late startup callbacks and later refresh batches from restarting work after shutdown.

## Install or update

1. Download **[CodexPlusBar.dmg](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.5/CodexPlusBar.dmg)** for macOS 14 or later, Apple silicon or Intel.
2. Quit CodexPlusBar. If its menu is missing, open it from Applications and press **⌘Q** in its window.
3. Open the DMG, drag **CodexPlusBar.app** to **Applications**, and choose **Replace** when updating.
4. Eject the DMG and reopen CodexPlusBar from Applications. Keep it running while fresh usage reaches Account Priority.

Profiles and saved sign-ins remain in place. iCloud Sync remains opt-in on each Mac; updating does not enable it.

## OpenChamber extension — included

This release includes a **freshly built [expiry-selector.zip](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.5/expiry-selector.zip)** containing Account Priority **0.1.0**. Extract it and install the **expiry-selector** folder in **OpenChamber → Settings → Extensions**. The extension is optional and installed separately from the DMG; its version is independent of the Mac app version.

**[SHA256SUMS](https://github.com/withLinda/CodexPlusBar/releases/download/v1.7.5/SHA256SUMS)** covers both downloads.

## Verification

- 106 targeted Swift tests in six affected suites cover startup, cloud recovery, profile operations, menu presentation, selector publishing and OpenChamber synchronization. No full-suite run.
- Controlled cloud barriers reproduced the missing menu and stale publisher before the fix; additional regressions cover native-drain concurrency, manual recovery actions and cancellation.
- Normal LaunchServices validation of the signed corrected app produced a fresh trusted 45-account export in 2.73 seconds. The menu opened normally; Account Priority reported Auto with no blocked reason or maintenance holds.
- The universal app and DMG are Developer ID-signed, notarized by Apple and stapled. Release preparation rebuilds and validates the extension ZIP and checksums; publication verifies downloaded assets before marking the release Latest.
